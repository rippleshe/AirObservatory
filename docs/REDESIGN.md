# AirObservatory 可视化改革计划 v2

> 2026-10-03 · 依据用户第五轮反馈制定。原则不变：文字最少化、可视化第一、不要现成图表库的默认质感、按功能分层而非数据句分层。

## 设计铁律（本轮确立）

1. **标题 = 功能，不是结论。** 大黑数据句（"22:00–23:00 浓度最高""北京 领跑 · 30 天排名流动"）一律取消。区块标题只写 2–4 字功能词（构成 / 排名 / 风场 / 联动 / 指纹 / 趋势…），小号、弱色、宽字距；独有数据结论降级为图表内的小注或直接删除。
2. **一个区块一层字。** 面板组件内部禁止再出现第二层标题（第六轮已立，本轮把"浅色小字堆"也纳入：图例、说明行、方法注全部能删则删）。
3. **图要"重绘"，不是"调用"。** ECharts 默认质感 = 讨厌项。核心图手写 SVG/canvas；ECharts 只在复杂坐标系下使用且必须深度定制。

## P0 功能修复

- [x] **城市切换失效**：顶栏下拉只写了 context store，没有跳转路由——城市页选了别的城市永远不动。修复：下拉选择即 `router.push` 到目标城市；总览页也显示切换器，选择即进城市页。

## P1 标题体系反转（大刀阔斧）

- 全国页 hero：大结论句 → 功能词"全国空气场"+ 图上小芯片承载数据读数
- 全国页 4 个 viz-head：污染构成 / 排名 × 风场 / 城市联动 / 污染模式，全部小功能词；chordHeadline、roseHeadline、dominantPollutant 长句全删
- 城市页 5 个 section：与锚点导航同词（趋势/构成/节律/结构/回测），删除 trendHeadline / pollutantHeadline / rhythmHeadline / structureHeadline / trustHeadline / windHeadline / waterfallHeadline / forecastOutlook 全部句子
- 标题样式：11px、宽字距、muted——是"层标签"，不是"新闻标题"

## P1 三张图重绘升级

1. **瀑布图**（质感最差点名项）：细圆角棒 + 涨跌渐变、首末锚定线（虚线水平基准）、hover 十字与数值签、逐棒错峰入场、末棒收束动画
2. **风玫瑰**：24 方位加密、径向渐变花瓣、外圈速度刻度环、最大瓣微光晕、旋转扫入动效、hover 扇区高亮
3. **弦图 → 真丝带弦图**：细线束升级为填充丝带（双弧贝塞尔，宽度∝|r|，源→target 渐变），节点按聚类排序成色环，hover 邻接提亮/其余压暗，入场旋转展开

### 2.3 海拔 / 人口 / 路网与工业：实测结论

**海拔（可全量取到，别重试别犹豫）**

- 接口：`https://api.open-meteo.com/v1/elevation?latitude=..&longitude=..`，**一次最多 100 个点**（`latitude`/`longitude` 交替传参）。
- 复测（2026-10-16）：**181 城 × 5 点（中心 + 0.25° 四向）＝ 905 点 / 10 次请求**，**181/181 城全部有值，0 个 null**（这解释了"905 点"这个数字：它是全量 181 城 × 5，不是 121 城）。
- 耗时：无退避约 20 秒；**连续请求会 429**，必须留间隔/退避（带退避实测 99 秒）。
- 五点极差当作"地形起伏/通风"的代理量：实测 **2–1749 m**（上海 5 m 到高原城市 1749 m），量级可用。

**人口（Open-Meteo geocoding 的 GeoNames 记录，13 个 NULL 全部可救）**

- 上一轮实测 108/121 有值，13 个 NULL。原因：**裸城市名经常返回同名村庄记录（`population` 为空）**，例如"舟山"命中浙江金华的一条 `PPLA4` 村庄。
- 本轮复测：这 13 个**按 `<城市名>市` / 拼音 / 旧名重查全都有值**——东营 998,968、安阳 1,146,839、周口 505,171、岳阳 991,465、邵阳 753,194、芜湖 1,598,165、德阳 735,070、九江 1,164,268、**普洱 296,565（查"思茅"）**、榆林 90,870、枣庄 899,753、阳江 1,292,987、**舟山 882,932（查 `Zhoushan`）**。
- **真正取不到的只有日喀则**：西藏只返回"日喀则和平机场"（`AIRP`）记录，没有可用的市区人口记录。→ `city_geography.csv` 里留空并在文档注明，**不要猜、不要造**。

**路网与工业用地（合成，别再试真实源）**

- Overpass 全镜像都试过：406 / 500 / 403 / 超时，不可用。
- Geofabrik 中国 pbf = 1.61 GB，下载 + 解析成本与收益不成比例。
- 结论：**路网密度与工业用地占比用合成值**，在 `city_geography.csv` 里用列名/来源列标清是合成的；真实值只保留海拔、起伏、人口三项。

**港澳台查询（不查 `countryCode=CN`）**

- 加 `countryCode=CN` 会把港澳台全部过滤掉——它们的 `country_code` 分别是 **HK / MO / TW**。
- 省份校验在港澳台失效：香港、澳门的 `admin1` 是 `None`；台北市是 `臺灣省 or 台灣省`，高雄市是 `高雄市`。→ 改用 `country_code ∈ {HK, MO, TW}` 接收。
- 中文名查不到台湾城市（"台北"无结果、"高雄"命中四川绵阳的同名地），要用 `Taipei` / `Kaohsiung`。
- 已实测可用记录：香港 1819729（22.278, 114.175，pop 7,396,076）、澳门 1821274（22.201, 113.546，pop 649,335）、台北市 1668341（25.053, 121.526，pop 7,871,900）、高雄市 1673820（22.616, 120.313，pop 2,737,660）。

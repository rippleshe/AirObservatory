# Air Observatory 选题报告

**题目：Air Observatory——多源空气质量时空可视分析与预测系统**

## 一、选题背景与意义

空气污染具有显著的时空异质性，其浓度变化不仅表现为不同地区之间的空间差异，还受到气象条件、污染物间关联及时间变化规律的共同影响。单一监测数据或静态统计图难以完整呈现这些复杂特征。与此同时，地面监测、数值模式与气象再分析数据在覆盖范围、时间分辨率和数据性质上存在差异，如何对多源数据进行有效整合、比较分析与可视化表达，是空气质量研究中的重要问题。

本项目以空气质量时空演变及其关联结构为研究对象，构建集多源数据管理、交互式可视分析、统计建模与预测评估于一体的研究系统，为污染变化规律探索、区域差异比较及预测模型分析提供支持。

## 二、目标受众及其特点

本项目主要面向环境科学、大气科学、数据科学等领域的科研人员，以及从事空气质量数据分析与建模的研究群体。

该类用户关注的不仅是某一时刻的空气质量水平，更重视数据的时空变化规律、污染物与气象变量的统计关联、不同数据来源之间的一致性，以及预测模型的性能与可靠性。因此，系统需要支持多时间尺度的数据探索、多变量联动分析、统计结构提取和模型对比，同时清晰呈现数据来源、时间范围、缺失情况及评估结果，以满足研究过程中的可解释性与可复核性需求。

## 三、研究内容与建设目标

项目围绕空气质量数据的空间分布、时间演变、多变量关联与未来变化展开，建立从数据获取到分析评估的完整流程。

首先，构建全国与城市两个层级的交互式时空可视化界面，通过地图、时间轴及多维统计图形展示污染物浓度的空间差异、历史演变与区域变化特征。

其次，结合气象变量与多种污染物数据，利用相关分析、主成分分析和探索性聚类等方法，研究空气质量的多变量关联结构与城市间的相似性，为潜在影响因素及污染模式的进一步研究提供线索。

最后，建立基于时间序列的预测与评估模块，利用 LSTM 等模型探索污染物浓度的短期变化，并与持续性预测、滑动均值等基准方法比较，通过分预测时距的误差分析和历史回测评估模型表现。

项目最终形成一个兼具数据探索、统计分析、预测建模与结果验证能力的交互式研究系统。

## 四、数据来源

- **OpenAQ**：获取可用城市及监测站点的地面空气污染物观测数据，用于实测变化分析、数据对照及具备充分样本条件下的模型验证。
- **CAMS（哥白尼大气监测服务）**：通过 Open-Meteo 提供的数据接口获取空气质量模式分析与预测数据，用于跨区域污染分布、历史演变和预测研究。
- **Open-Meteo 气象历史数据**：获取温度、湿度、风速、风向、气压、降水等气象变量，为污染物与气象条件的联合分析提供数据支持。
- **城市静态解释变量**：海拔、地形起伏与城市人口取自 Open-Meteo 的高程接口与地理编码接口（GeoNames 记录）；
  路网密度与工业用地占比为合成值——公开免费的真实来源不可达（Overpass 各镜像返回 406/500/403/超时，
  Geofabrik 中国数据 1.61 GB），排放强度由它们派生。真实列与合成列在 `backend/city_geography.csv` 中逐行标明，
  用于解释城市之间的差异并作为多变量分析的解释变量。

系统对地面观测、模式分析和预测结果分别管理，并记录来源与时间信息，避免不同性质的数据在分析和可视化过程中被混淆。

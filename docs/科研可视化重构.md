# 科研定位与可视化重构

定位：以环境科学、大气科学与数据科学研究人员为主要受众；课程评审是展示场景，而非产品用户。选题正式表述见 `选题报告.md`。

## 研究工作流

**确定范围 → 核查数据 → 探索时空模式 → 对比变量关系 → 评估预测 → 保存证据。**

- 全国：统一时间窗和来源口径的空间比较；地区选择应驱动其他图联动。31 省代表是一种展示归约，不等价于省平均值。必须显式标记代表规则和覆盖。
- 城市：历史数据与地面观测同轴呈现但保持独立系列，优先支持时段选择和模型—观测配对；滞后超过阈值禁止展示差值。
- 结构：相关矩阵说明样本数及方法；PCA 提供解释方差、载荷、时间点得分与完整案例；聚类只作为探索线索而非环境类型定论。
- 预测：区分 CAMS 预测、模型分析序列上的 LSTM 预测和地面真值；明确训练目标、输入窗、预测步长、数据切分，展示每个 horizon 的 MAE/RMSE、基线与样本数。
- 数据与方法：来源覆盖、缺失、时效、数据版本、模型版本、提取窗口可审阅；必要时支持结果导出以便复核。

## 现有图表的处理原则

| 现有组件 | 重构方向 | 研究价值 |
| --- | --- | --- |
| ChinaFieldMap / TimeRibbon | 同步时间切片、来源与采样覆盖，省代表规则明确 | 空间异质性与时间变化 |
| SeverityBand / PollutionWeave | 统一 cohort 与时间窗，直接暴露单位、分位数和有效样本 | 分布比较 |
| StreamGraph | 明确各层是否可加以及值的物理量纲；不适合相加时改并列轨道 | 多污染物时间结构 |
| WindRose / ChordDiagram | 风向频率、相关系数、样本量和时间窗；严禁相关推因果 | 气象关联与城市同步性 |
| CityFingerprintPanel | 标准化范围、PC 载荷、解释率和聚类质量 | 多变量结构 |
| TraceDeck / PCAStructurePanel | 对齐时间、缺失处理、分布位置与散点联动 | 城市结构解释 |
| LstmEngine / BacktestAnatomy | 预测目标与训练/验证时段、真实误差对照优先于门控动画 | 预测可验证性 |

## 实施顺序

1. **P0 数据语义**：逐图核实模型场/观测/预测来源，统一更新时间、时区、有效样本和缺失含义；不要把样本不足渲染成“训练中”。
2. **P1 研究性交互**：全国及城市页增加跨图统一时窗/变量/地点过滤。选中时，各图采用同一数据 cohort、时间窗和单位；现有底图点选入口保留。
3. **P1 模型证据**：突出基线对比、分 horizon 的回测误差和训练目标；门控图保留为可探索细节而不是模型正确性的证明。
4. **P2 论文式分析复核**：图表导出、数据表格孪生、方法定义及样本/版本参数留痕。
5. **P2 表现力**：在数据诚实、分析可读之后调整视觉密度、字体、颜色和动效，优先桌面及课堂投影。

## 验收条件

- 同一时窗下图表数值可以从数据库/API 复核；无合成填充值；
- 31 省代表与 60 城事实分开，模型场与地面实测分开；
- 时序交互不会使各图的年份、时区或筛选条件失配；
- 预测指标具有明确监督目标、测试样本与计算方法；
- `uv run python -m pytest -q`、`uv run ruff check backend scripts tests`、`pnpm run build` 完成；Playwright 验收桌面、窄屏、加载和空数据状态。

**口径**：本文件与 `PRODUCT.md` 是本项目唯一的权威设计规范，受众为科研人员；`选题报告.md` 是同一口径的选题正式表述，`协作指南.md` 是分工与流程规范。
